# spikes/

M0 fizibilite denemeleri (Mimari §13, §14). Buradaki kod:

- çalışma alanına **dahil değildir** (her spike kendi `Cargo.toml`'u ile bağımsızdır),
- kalite kapılarına tabi değildir ve ana koda kopyalanmaz,
- sonucu `docs/m0/checklist.md`'ye "geçti / kaldı" + kanıt olarak yazılır.

Bir spike'tan öğrenilen, ana koda tasarım belgesi + test + kod sırasıyla yeniden yazılır.
